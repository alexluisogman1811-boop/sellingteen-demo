How results are recorded

  • Everything is manual. A task is only marked completed when you record it, with the date, result and notes you enter.
  • SiteCare Desk does not run backups, uptime monitoring, performance tests or security scans, and never assumes they succeeded.
  • Evidence files (screenshots, PDFs, logs) are optional proof you attach yourself.
  • Credentials are never collected. Notes that look like passwords, API keys or tokens are rejected.
