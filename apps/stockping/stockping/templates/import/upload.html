  • Prices use a dot for decimals with at most 2 places (12.50); no currency symbols.
  • Quantities and thresholds are whole numbers, 0 or more.
  • Rows whose SKU already exists are skipped; existing products are never overwritten.
  • Duplicate SKUs inside the file are errors. If any row has errors, nothing is imported.
  • Unknown supplier names are created as new suppliers.
  • Each imported quantity is recorded as an "Opening stock" movement.
